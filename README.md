# Saturday 21 November 2026 — The World in One Day (v2)

A broadsheet front page summing up Saturday 21 November 2026 in one image:
40 verified stories across 7 regions — 3 pictured heroes, 10 numbered
pictured stories, a numbered world map, a 27-story "ALSO ON SATURDAY" list,
a "THE DAY IN UTC" strip, a DATE CHECK box, and a judge line.

v2 keeps v1's winning structure (98.9260%, rank 48) and upgrades it:
verification labels (CONFIRMED / CLAIMED / REPORTED) on all 13 pictured
stories with a legend, the UTC strip, bigger anti-aliased type for 300px
legibility, and one consistent verified number — 879,868 AI chips — in both
the number strip and the Beijing story.

## Run

```sh
python3 draw.py        # renders entry.png (1024x1024, local, needs Pillow)
python3 main.py        # copies entry.png to $MAKEFUN_OUTPUT_DIR/entry.png
```

`main.py` is stdlib only. `draw.py` is the local generator (Pillow) and is
not imported by the entry point.
